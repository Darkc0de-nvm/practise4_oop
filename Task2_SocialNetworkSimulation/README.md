## Про проєкт

Програма емулює роботу простої соцмережі в терміналі. Під час запуску користувач обирає одного з кількох заздалегідь створених профілів, після чого може переглядати чужі пости, ставити лайки, писати коментарі, а також створювати та видаляти власні пости.

Дані зберігаються **лише в оперативній пам'яті**.

---

## Можливості

| Дія | Опис |
|-----|------|
| Перегляд постів | Показує останні 5 постів обраного користувача (від новіших до старіших) |
| Лайк | Поставити лайк посту іншого користувача |
| Коментар | Залишити коментар під постом іншого користувача |
| Створення посту | Опублікувати власний пост (порожні тексти відхиляються) |
| Видалення посту | Видалити один зі своїх постів |
| Власні пости | Переглянути всі свої пости з лайками та коментарями |

Додатково:

- валідація введення (некоректні номери, порожні тексти);
- підтримка української мови в консолі (UTF-8);
- автоматична фіксація дати й часу створення поста.

## Технології

- **Мова:** C#
- **Платформа:** .NET 6 або новіша
- **Тип застосунку:** консольний
- **Зовнішні бібліотеки:** не використовуються (лише `System.Text`)

> Код не містить директив `using` для `System`, та `System.Collections.Generic`, оскільки використовує неявні імпорти (`ImplicitUsings`), які ввімкнені за замовчуванням у стандартному шаблоні консольного проєкту .NET 6+.

## Як користуватися

1. Після запуску з'явиться список користувачів — введіть номер потрібного.
2. У головному меню оберіть дію, ввівши її номер.

```text
Parodygram

Користувачі:
1. Олександр (@alex)
2. Марія (@maria)
3. Льоха (@lyoha)

Оберіть користувача: 1

Поточний користувач: @alex
1. Переглянути останні 5 постів користувача
2. Поставити лайк
3. Написати коментар
4. Створити новий пост
5. Видалити свій пост
6. Переглянути свої пости
0. Вийти

Оберіть дію:
```

Приклад перегляду поста:

```text
Пост №3
Дата: 28.10.2026 14:05
Текст: Працюю над новим завданням.
Лайків: 2
Коментарі:
@maria: Успіхів!
-----------------------------
```

### Стартові користувачі

| Ім'я | Нікнейм | Кількість початкових постів |
|------|---------|:---------------------------:|
| Олександр | `@alex` | 3 |
| Марія | `@maria` | 6 |
| Льоха | `@lyoha` | 2 |

Така різниця в кількості постів зроблена навмисно — щоб перевірити, що функція «останні 5 постів» працює коректно.

## Архітектура

Увесь код розділено на логічні класи за відповідальністю.

```text
SocialNetwork ──┬── User ──┬── Post ──┬── Comment (struct)
                │          │          └── Likes (int)
                │          └── Post ...
                └── User ...
```

| Тип | Вид | Призначення |
|-----|-----|-------------|
| `Comment` | `struct` | Коментар: автор і текст. Легкий тип-значення |
| `Post` | `class` | Пост: дата створення, текст, лайки, список коментарів |
| `User` | `class` | Користувач: ім'я, e-mail, нікнейм, список власних постів |
| `SocialNetwork` | `class` | «Платформа»: зберігає список користувачів і початкові тестові дані |
| `Program` | `class` | Точка входу, головне меню та допоміжні методи введення/виведення |

### Основні методи

**`Post`**
- `AddLike()` — збільшує лічильник лайків;
- `AddComment(author, text)` — додає коментар;
- `ShowInfo()` — виводить інформацію про пост.

**`User`**
- `CreatePost(text)` — створює й додає новий пост;
- `DeletePost(post)` — видаляє пост зі списку;
- `ShowPosts(count)` — виводить пости від новіших до старіших (за замовчуванням — усі).

**`SocialNetwork`**
- `ShowUsers(excludedUser)` — виводить список користувачів, за потреби без поточного.

**`Program`**
- `SelectOtherUser` — вибір іншого користувача зі списку;
- `SelectPost` — вибір поста конкретного користувача;
- `SelectOtherUserPost` — комбінація двох попередніх (використовується для лайків і коментарів);
- `ShowOtherUserPosts`, `LikePost`, `CommentPost`, `CreatePost`, `DeletePost`, `ShowOwnPosts` — обробники пунктів меню.

## Як це працює

1. **Ініціалізація.** У `Main` налаштовується кодування UTF-8 і створюється `SocialNetwork`, у конструкторі якого додаються три користувачі та їхні початкові пости.
2. **Вибір профілю.** Користувач вводить номер, який перевіряється через `int.TryParse` і порівнюється з межами списку.
3. **Головний цикл.** `while (true)` показує меню, зчитує вибір і через `switch` викликає потрібний метод. Вихід — пункт `0` (або завершення введення).
4. **Взаємодія з чужими постами.** Для лайків і коментарів спочатку обирається інший користувач, потім його пост. Власного користувача зі списку виключено, тож лайкнути чи прокоментувати свій пост неможливо.
5. **Останні пости.** `ShowPosts(5)` обчислює початковий індекс як `Math.Max(0, Posts.Count - count)` і виводить пости зворотним порядком, тому завжди показуються найновіші.
6. **Валідація.** Порожні або пробільні тексти постів і коментарів відхиляються через `string.IsNullOrWhiteSpace`; некоректні номери обробляються повідомленням про помилку без падіння програми.
